# Khôi phục cách tìm bằng @

- **Tên Plugin nội bộ giữ nguyên:** `hoang-phuong-supercomputing-ai-core`.
- **Tên hiển thị mới:** `hoangphuong-supercomputing-core`.
- Thêm từ khóa tìm kiếm và skill bí danh; bảo toàn toàn bộ nội dung 7 skill gốc.
- Đây là cập nhật metadata, **không phải** quyền can thiệp trực tiếp vào bộ gợi ý @ của giao diện.
- Trong ChatGPT, mở Plugins → Personal / Created by you, tìm đúng plugin → Install nếu hiện nút này; sau đó thử trong chat mới `@hoangphuong` hoặc `@hoangphuong-supercomputing-core`.
- Nếu menu @ không hiện, dùng + → Plugins và chọn plugin, hoặc kiểm tra phiên đăng nhập/workspace.
- Không cài lại thành bản thứ hai.
