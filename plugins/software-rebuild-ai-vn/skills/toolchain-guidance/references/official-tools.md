# Danh mục công cụ chính chủ được tham chiếu

| Công cụ | Nguồn chính chủ | Mục đích | Giới hạn |
|---|---|---|---|
| JADX | https://github.com/skylot/jadx | Android Dex/APK -> Java tham khảo | Không khôi phục 100% mã gốc; Apache-2.0 |
| Apktool | https://apktool.org/ | Android resource/manifest/smali | Không dùng để sao chép phát tán trái phép; Apache-2.0 |
| MobSF | https://github.com/MobSF/Mobile-Security-Framework-MobSF | Phân tích bảo mật mobile | GPL-3.0; xem giấy phép/phiên bản riêng |
| Ghidra | https://github.com/NationalSecurityAgency/ghidra | Binary Windows/macOS/Linux | Native decompile chỉ mang tính xấp xỉ; đọc security advisory |
| ILSpy | https://github.com/icsharpcode/ILSpy | .NET assemblies | MIT; khôi phục source có giới hạn |
| Frida | https://frida.re/ | Instrumentation động | Chỉ dùng trên app/thiết bị được phép; cần đánh giá pháp lý và bảo mật |
| Playwright | https://playwright.dev/ | Kiểm thử UI browser | Không tự động cung cấp quyền truy cập website |
| Chrome DevTools | https://developer.chrome.com/docs/devtools/ | Khảo sát DOM/performance/network cho web | Chỉ xem dữ liệu truy cập hợp pháp |
| Android Studio | https://developer.android.com/studio | Phát triển/debug Android | Cần setup SDK/emulator |
| Xcode | https://developer.apple.com/xcode/ | Build/debug iOS/macOS | Cần macOS |
| OWASP MASTG | https://mas.owasp.org/MASTG/ | Kiểm thử bảo mật mobile | Tài liệu, không phải phần mềm decompile |

Luôn tra cứu bản release và license hiện hành trước khi cài. Danh mục là liên kết tham khảo, không đồng nghĩa đã cài tool vào ChatGPT hay Windows.
