# ChatGPT adapter

Use this adapter when importing the repo into a ChatGPT-style plugin or assistant environment.

## Entry points

- `SKILL.md`
- `plugin.json`
- `README.md`
- relevant plugin folders under `plugins/`

## Adapter instructions

- Treat this repository as a portable skill pack and migration toolkit.
- Prioritize repo-aware reasoning and packaging guidance.
- Keep safety and neutrality: do not claim live deployment unless proven.
- Use the supplied plugin metadata only as a packaging description, not as proof of runtime operation.

## Typical tasks

- analyze repo and propose skill packaging
- convert project into multi-platform AI skill format
- prepare migration steps to another AI host
- write installation and validation guidance
