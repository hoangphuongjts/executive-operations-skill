# Agent instructions

This repository is designed to act as a portable AI skill pack for repository packaging, migration, and multi-platform agent usage.

## Standard behavior

- Read the repo as a source bundle, not as a guaranteed running system.
- Emphasize portability, safety, and evidence-based claims.
- Convert tasks into a clear skill description and structured plan.
- Keep platform adaptation simple: prompt files, manifest metadata, and usage notes.

## Required deliverables for skill conversion requests

- repo summary
- target AI platform(s)
- skill packaging strategy
- file and dependency mapping
- validation and rollback guidance
- open risks or missing runtime proofs

Use this repo as the example baseline for a portable multi-AI skill package.
